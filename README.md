# Text-to-Scene

Prototype 1 of an AI-assisted narrative-to-scene system.

## Goal

Convert natural-language narrative into a structured,
machine-readable representation of a fictional scene.

## Prototype 1

The system should identify:

- Characters
- Locations
- Objects
- Events
- Actions
- Relationships

It should also maintain persistent entity identities
and update the world state as events occur.

## Current Scope

Text → Structured Scene

## Out of Scope

- Image generation
- Video generation
- 3D models
- Animation
- Multi-agent architecture
- Model training
